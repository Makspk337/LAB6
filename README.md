Цели и задачи работы: изучение СУБД PostgreSQL и практическое использование PostgreSQL для хранения и обработки данных.
Язык СУБД: PostgreSQL.
Языки программирования: C++, Go или Rust.
Задание к работе: создать базу данных (БД) и таблицы в СУБД PostgreSQL, интегрировать базу данных в программу, написать запросы к базу данных. Тема базы данных и содержимое таблиц определяется студентом самостоятельно.
Методика выполнения работы:
1.	Разработать алгоритм решения задачи.
2.	Создать базу данных (БД) и таблицы в СУБД PostgreSQL.
3.	Написать и отладить программу решения задачи (С++, Go или Rust).
4.	Интегрировать базу данных (БД) в программу.
5.	Написать запросы к таблицам.
6.	Протестировать работу программы на различных исходных данных.
7.	Продемонстрировать работу с СУБД PostgreSQL на примере написанной программы.
8.	По запросу преподавателя быть готовым модифицировать/добавить функционал программы.
9.	Ответить на теоретические вопросы к лабораторной работе на выбор преподавателя.
Состав отчета:
1.	Титульный лист.
2.	Цель работы.
3.	Тема БД и содержимое таблиц.
4.	Схема БД
5.	Листинг программы и запросов.
6.	Результат работы программы.

Требования к БД:
1.	БД должна быть реализована в СУБД PostgreSQL.
2.	Тема БД определяется студентом самостоятельно, но не должна совпадать с темами других студентов из одной и той же группы.
3.	БД должна быть интегрирована в программу, написанной на C++, Go или Rust.
4.	В БД должно быть минимум пять таблиц. Содержимое и назначение таблиц определяется студентом самостоятельно.
5.	Все таблицы должны быть связаны, связи должны быть явно указаны.
Требования к запросам:
1.	Должно быть написано десять различных запросов к БД. Либо могут быть написаны пять обычных запросов и пять SQL-инъекций.
2.	Запросы должны различаться по цели.
3.	В запросах (не обязательно во всех) должна быть использована команда JOIN и ее вариации.
4.	В запросах (не обязательно во всех) должна быть использована команда WHERE или HAVING.
5.	В хотя бы одном запросе должно быть показано использование агрегатной функции.
6.	Крайне желательно разнообразие используемых в запросе команд и построение сложных запросов.

Структура проекта:
main.cpp - Программа на C++;
queries.sql - SQL запросы;
tables.sql - Таблицы.
